# Interactive WebGL Fluid Simulation

A high-performance, real-time 2D fluid dynamics simulation built with WebGL and HTML5 Canvas.

## Features
- **Real-Time Physics:** Smooth GPU-accelerated fluid simulation using WebGL shaders.
- **Interactive UI:** Customizable color modes (Rainbow, Neon, Single Color), flow speed, and vortex density.
- **Cross-Platform:** Touch-enabled for mobile devices and responsive full-screen support.
- **Themes & Styles:** Includes multiple visual styles (Smoke, Dots, Neon Lines, Pixel, Thermal, Aurora, and more).

## Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
- WebGL / GLSL (Shaders)

## Privacy Policy & About
This application runs entirely in your web browser using WebGL technology. It does not store or process personal data on external servers.
